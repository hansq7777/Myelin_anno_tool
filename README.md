# Myelin_anno_tool
unsupervised annotation tool for deep learning data collection

## Running the GUI

Install the dependencies (e.g. `PyQt5`, `tifffile`, and `numpy`) and
run the application from the repository root using one of the
following commands:

```bash
python -m zstack_anno      # execute the package
# or
python main.py             # run the helper script

This will launch the annotation window defined in `zstack_anno`.
